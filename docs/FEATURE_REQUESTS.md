# Feature Requests

## 1. Public Alexa+ Add-on simulator — Critical
A browser-accessible simulator would let developers validate conversation turns, cards, error states, and session continuity against a more representative Alexa+ surface without requiring partner preview access.

## 2. Simulation starter repository — Important
Provide an official minimal repo showing a compliant simulated Alexa+ experience, including recommended disclosure language, demo expectations, and example stateful multi-step flows.

## 3. State/handoff design guidance — Nice-to-have
Add examples for long-running workflows where an external action can be attempted but not confirmed. This would help developers avoid optimistic completion assumptions in transportation, home services, caregiving, and commerce flows.
